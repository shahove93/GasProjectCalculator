# GasProjectCalculator

Веб-калькулятор стоимости работ по газовым проектам: ГСН, ГСВ и общая смета
ГСН + ГСВ. Вводишь параметры объекта — получаешь расшифровку расчёта с НДС.

## Установка на Windows

Для обычного пользователя готовый установщик уже собран локально: **Python и
командная строка не нужны**.

1. Откройте установщик:
   `D:\Antigravity\GasProjectCalculator\installer\Output\GasProjectCalculator-Setup-1.0.0.exe`
   (размер 15 256 037 байт, SHA256
   `2973278F47A4A2A479177B12A4C4CCA01ED59D1CA8D2D9CE107C4E7A2E37428F`).
2. Запустите его и пройдите мастер установки. Установка выполняется только для
   текущего пользователя, в каталог
   `%LOCALAPPDATA%\Programs\GasProjectCalculator`; права администратора не
   требуются.
3. Запустите приложение из меню **Пуск** → **GasProjectCalculator**. Ярлык на
   рабочем столе создаётся только при выборе необязательного пункта в мастере
   (по умолчанию пункт снят).

Установщик — **неподписанный локальный артефакт**: кодовая подпись не
выполнялась, поэтому Windows SmartScreen может показать предупреждение при
первом запуске. Это ожидаемо.

Приложение открывается в собственном окне. Бэкенд слушает только localhost
(`127.0.0.1`) и наружу ничего не публикует; другие компьютеры в сети к нему не
подключаются. Закрытие окна останавливает приложение и освобождает порт. Файлы
пользователя (журнал приложения) пишутся в
`%LOCALAPPDATA%\GasProjectCalculator`, а не в каталог установки, поэтому удаление
программы их не затрагивает.

### Удаление

Параметры Windows → Приложения → Установленные приложения →
**GasProjectCalculator** → **Удалить**. Удаляются файлы программы и ярлыки;
пользовательские файлы в `%LOCALAPPDATA%\GasProjectCalculator` сохраняются.

## Что умеет калькулятор

- Три режима: ГСН, ГСВ, ГСН + ГСВ (общая смета).
- Рассчитывает стоимость подключения газа для частного и юридического лица.
- ГСН учитывает: длину трассы, углы, экскаватор, ГНБ, район, ГРПШ.
- ГСВ учитывает: длину, диаметр, алмазное бурение, комплекты САКЗ, ПК и район.
- Показывает расшифровку: базовая стоимость, каждая доплата отдельно, подытог,
  НДС 5% и итог; в общем режиме — оба раздела и общий итог.
- Валидирует входные данные на сервере (HTTP 422 при некорректных значениях),
  включая ПК без САКЗ и диаметр больше 57 мм.
- Интерфейс: HTML-форма → JavaScript → FastAPI
  (`POST /calculate`, `POST /calculate/gsv`, `POST /calculate/combined`);
  открывается в окне приложения, а при запуске из исходников — в браузере.

## Бизнес-правила GSN v1.0

- Частник: базовая стоимость **65 000 ₽** до 10 м.
- Юрлицо: базовая стоимость **85 000 ₽** до 10 м.
- Каждый метр сверх 10 м: **+3 000 ₽**.
- Угол: **+3 000 ₽** за каждый.
- ГНБ: **+40 000 ₽**.
- При ГНБ экскаватор **не рассчитывается**.
- Экскаватор: согласно существующим правилам (до 2 ч — 9 000 ₽ / 10 000 ₽ с молотом, далее 3 000 ₽ / 3 500 ₽ за час).
- Район: **+7 000 ₽**.
- ГРПШ: **+40 000 ₽**.
- НДС: **5%** от подытога, в конце.

## Бизнес-правила ГСВ

- База за длину до 5 м включительно: частник **60 000 ₽**, юрлицо **80 000 ₽**.
- Каждый метр сверх 5 м: диаметр до 25 мм — **2 500 ₽**, 26–40 мм — **3 500 ₽**,
  41–57 мм — **4 000 ₽**. Диаметр больше 57 мм отклоняется.
- Алмазное бурение: без услуги **0 ₽**, за 1–2 отверстия **8 000 ₽**,
  за 3 и более — **10 000 ₽**.
- САКЗ: количество комплектов × **14 000 ₽**.
- ПК: **4 000 ₽**, доступен только при наличии хотя бы одного комплекта САКЗ;
  ПК без САКЗ отклоняется сервером (422) и блокируется/сбрасывается в интерфейсе.
- Район: **+7 000 ₽** к каждому разделу; в общей смете — **+14 000 ₽** до НДС.
- НДС: **5%** после сложения базы и всех доплат.

## Для разработчика (запуск из исходного кода)

Разделы ниже нужны только для работы с исходным кодом. Обычному пользователю
достаточно установщика из раздела «Установка на Windows».

### Установка зависимостей

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Запуск сервера

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

### Где открыть приложение

После запуска сервера откройте в браузере:

```
http://127.0.0.1:8000/
```

### Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

### Запуск из исходного кода на другом компьютере

Эта инструкция — только для запуска из исходного кода. Обычному пользователю
нужен установщик из раздела «Установка на Windows».

1. Установите Python 3.10 или новее с сайта [python.org](https://www.python.org/downloads/windows/).
   В установщике включите **Add Python to PATH**.
2. На [странице ветки feature/gsv в GitHub](https://github.com/shahove93/GasProjectCalculator/tree/feature/gsv)
   нажмите **Code → Download ZIP**, затем распакуйте архив.
3. Откройте PowerShell в распакованной папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app
```

4. Откройте <http://127.0.0.1:8000/> в браузере. Чтобы остановить сервер,
   нажмите `Ctrl+C` в PowerShell.

## Устранение неполадок и данные пользователя

- Приложение не запускается и показывает окно с ошибкой: чаще всего не
  установлен компонент **Microsoft Edge WebView2 Runtime** (входит в актуальные
  версии Windows) либо антивирус блокирует запуск. Текст причины и путь к
  журналу показываются в самом диалоге.
- Журнал приложения: `%LOCALAPPDATA%\GasProjectCalculator\logs\desktop.log`.
- Бэкенд работает только локально: порт выбирается начиная с 8000, занятые
  порты пропускаются, прослушивается только `127.0.0.1`. Другие компьютеры в
  сети к приложению не подключаются.
- Каталог установки — `%LOCALAPPDATA%\Programs\GasProjectCalculator`. Файлы
  пользователя и журналы хранятся вне его (в
  `%LOCALAPPDATA%\GasProjectCalculator`) и при удалении программы сохраняются.
