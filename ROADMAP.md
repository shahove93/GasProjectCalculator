# План этапа ГСВ

Статус: DESIGN, пакет готов к утверждению вместе с VISION и ARCHITECTURE.

| Шаг | Результат | Критерий завершения |
| --- | --- | --- |
| 1. Требования | Формулы, тарифы, поля, НДС, округление, примеры | Пользователь подтвердил правила и ожидаемые суммы |
| 2. Утверждение | Согласованные VISION, ARCHITECTURE, ROADMAP и Git-политика | Явное утверждение пользователя связано с версиями документов |
| 3. Подготовка workflow | Локальная конфигурация OpenCode и Orca-координатор | Проверены доступность выбранных моделей и фактическая маршрутизация; создан замороженный TASK-чек-лист |
| 4. Расчёт ГСВ | Изолированный модуль и тесты | Утверждённые примеры, тарифные границы и исключения совпадают |
| 5. API | Валидация, endpoints ГСВ и общей сметы, детализация | Позитивные/негативные проверки проходят; контракт ГСН сохранён; общие суммы совпадают с суммой разделов |
| 6. Интерфейс | Три режима, поля, результаты и ошибки | ГСН, ГСВ и ГСН + ГСВ работают в браузере и на мобильной ширине |
| 7. Итоговая приёмка ГСВ | Интегрированные проверки, README, evidence, отчёт | Завершено; см. FINAL-REPORT.md |
| 8. Windows installer | Упакованное приложение с отдельным окном, установщик и ярлыки | Чистая Windows x64 установка и запуск без Python/CLI; ГСН, ГСВ и общая смета работают; закрытие завершает сервер; удаление сохраняет пользовательские файлы |
| 9. Приёмка упаковки | Независимый risk-routed review, evidence и обновлённые README/отчёт | TASK приняты, Codex финально принял этап; installer хранится как проверенный артефакт для передачи пользователю |

Координатор уточняет границы TASK и фиксирует риск до dispatch. API — минимум
R2; новое архитектурное решение — R3. Простые задачи по готовому паттерну — R1,
механическая документация — R0. Не дробить архитектурную задачу для обхода ревью.
Независимое ревью обязательно по маршруту; завершение исполнителя не равно PASS.

После утверждения всего плана координатор последовательно выполняет согласованные
TASK без новых запросов на каждый переход. Windows installer одобрен отдельно
2026-11-11; его scope ограничен desktop приложением и локальным installer
artifact. Push/merge/deploy и публикация installer в GitHub Release не входят.
Новые требования или изменение архитектуры возвращаются пользователю на решение.
