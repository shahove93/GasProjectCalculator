# СС.Расчет 1.0.0 — Windows x64

Готовое приложение для расчёта стоимости ГСН, ГСВ и общей сметы.

- Компактное окно 800×540, фирменная эмблема ООО «Северное сияние».
- Расшифровка доплат, комплекты САКЗ, ПК и НДС 5%.
- Русский интерфейс, анимированная заставка и русский установщик.
- Python и команды PowerShell для использования не нужны.

## Установка

1. В разделе **Assets** скачайте **SS-Raschet-Setup.exe**.
2. Запустите файл и пройдите русский мастер. При желании включите ярлык рабочего стола.
3. Откройте **СС.Расчет** из меню «Пуск» или ярлыком.

Для обновления закройте приложение и запустите новый установщик. Расчёты
выполняются на вашем ПК. Требуются Windows x64 и Microsoft Edge WebView2 Runtime.
Установка выполняется для текущего пользователя без прав администратора.

Установщик не подписан: Windows SmartScreen может показать предупреждение.
Контрольная сумма приведена в приложенном **SHA256SUMS.txt**.
