# СС.Расчет 1.1.0 — Windows x64

Новая версия калькулятора для ООО «Северное сияние».

## Что изменилось

- В ГСВ и ГСН+ГСВ добавлены три независимые длины: **до Ø25**, **Ø32–40**, **Ø57**.
- Общий метраж и подробная разбивка включённых/оплачиваемых метров по категориям.
- Первые 5 м входят в базу один раз и вычитаются из самых дешёвых труб первыми.
- Обновлены верхняя и нижняя иллюстрации. Сохранены компактное окно, русские заставка и мастер установки.

## Установка и обновление

В **Assets** скачайте **SS-Raschet-Setup.exe**, закройте прежнее окно приложения
и пройдите мастер. Запускайте **СС.Расчет** из меню «Пуск» или ярлыком.
Права администратора, Python и команды PowerShell не нужны. Требуются Windows
x64 и Microsoft Edge WebView2 Runtime. Расчёты выполняются локально.
