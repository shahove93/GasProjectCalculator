# СС.Расчет 1.2.0 — Windows x64

Новая версия калькулятора для ООО «Северное сияние». Расчёты и данные
пользователя не менялись — обновлено оформление приложения и установщика.

## Что изменилось

- Новая тёмная шапка с трубой/вентилем и обновлённой нижней полосой по
  утверждённым референсам.
- Обновлённая заставка запуска в том же фирменном стиле.
- Установщик получил фирменную графику и сохранённый русский мастер.
- Небольшие дизайнерские улучшения в рамках утверждённого brief.
- Сохранены компактное окно, три режима расчёта (ГСН, ГСВ, общая смета),
  три длины ГСВ и русский интерфейс.

## Установка и обновление

В **Assets** скачайте **SS-Raschet-Setup.exe**, закройте прежнее окно
приложения и пройдите мастер. Запускайте **СС.Расчет** из меню «Пуск» или
ярлыком. Права администратора, Python и команды PowerShell не нужны.
Требуются Windows x64 и Microsoft Edge WebView2 Runtime. Расчёты выполняются
локально.
