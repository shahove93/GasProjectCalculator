## Ввод и результат

В режиме ГСВ и в секции ГСВ общей сметы заменить одиночные длину/диаметр на
три позиции с отдельными длинами:

| Позиция | Тариф за оплачиваемый метр |
| --- | ---: |
| до Ø25 | 2 500 ₽ |
| Ø32–40 | 3 500 ₽ |
| Ø57 | 4 000 ₽ |

Длины целые неотрицательные метры, ноль означает отсутствие этой позиции.
Показать общий метраж как сумму трёх длин. Базовая стоимость применяется один
раз на раздел ГСВ, а не на каждый диаметр. САКЗ, ПК, бурение, район и НДС
применяются после расчёта доплаты как прежде. В детализации показать длину,
включённые/оплачиваемые метры, ставку и сумму каждой позиции.

## Формула (подтверждена пользователем)

Пять базовых метров распределяются один раз в порядке возрастания тарифа:
до Ø25 → Ø32–40 → Ø57. Из текущей категории исключается минимум её длины и
неиспользованного остатка базовых метров. Остальные метры оплачиваются по
тарифу категории. Общая длина = сумма трёх длин; доплата = сумма категорий.
При сумме ≤5 доплата за длину 0. Нулевая длина всех категорий сохраняет
прежний смысл: базовая стоимость, а не бесплатный раздел.

Эталоны для частника в городе без опций (последние два столбца — с базой):

| до Ø25 / Ø32–40 / Ø57, м | Длина | Доплата | Подытог | Итог с НДС5% |
| --- | ---: | ---: | ---: | ---: |
| 4 / 0 / 4 | 8 | 12 000 | 72 000 | 75 600 |
| 2 / 4 / 3 | 9 | 15 500 | 75 500 | 79 275 |
| 0 / 5 / 2 | 7 | 8 000 | 68 000 | 71 400 |
| 3 / 1 / 1 | 5 | 0 | 60 000 | 63 000 |
| 8 / 0 / 0 | 8 | 7 500 | 67 500 | 70 875 |

Общий пример, частник/район: ГСН10 м без опций 75 600 с НДС; ГСВ4/0/4 без
остальных опций 82 950 с НДС; общий подытог151 000, НДС7 550, итог158 550.

## Архитектура

Новые длины валидировать на сервере; общий метраж и оплачиваемые метры
вычислять из них, а не принимать итог клиента. Общая смета использует тот же
модуль ГСВ и те же правила. Существующий однодиаметровый запрос и результаты
сохранить как compatibility path; неоднозначную смесь старого/нового ввода
отклонять. Расчёт ГСН не меняется.

Контракт нового ввода: `pipe_lengths` с тремя обязательными целыми полями
`up_to_25`, `from_32_to_40`, `diameter_57`. Все ≥0, bool/дроби/отрицательные
и неизвестные ключи запрещены. `length`/`diameter` допустимы только как полный
legacy pair без `pipe_lengths`; неполная/смешанная форма — 422. Это правило
общее для `/calculate/gsv` и nested `gsv` в `/calculate/combined`.
Для mixed-запроса ответ дополнить `total_length` и `pipe_breakdown`: category,
length, included_length, billable_length, rate, surcharge; итоговые денежные
поля сохранить. Legacy response сохраняет прежнюю форму без новых ключей.
Строгость legacy и его старые интервалы диаметров не менять.
