## Конкретный визуальный результат

### Шапка

Тёмно-синий широкий фон, спокойная полупрозрачная бирюзовая труба,
металлические муфты, **широкий горизонтальный золотой овальный маховик**
с ножкой и вентилем; изгиб трубы и композиция как в header-reference.
Убрать лишнюю вторую трубную ветку, пунктир/точки внутри трубы и чрезмерное
неоновое свечение. Маховик полностью виден, не обрезан viewBox/контейнером.
Текст/режимы остаются интерактивными и читаемыми, труба не мешает им.

### Нижняя полоса

Лёгкий светлый фон, **тонкая контурная труба** с муфтами, голубое пламя
слева и целиком видимый дом с тёплым окном справа; дерево/кусты и мягкая
линия земли по footer-reference. Без массивной тёмной трубы/неонового пунктира,
без обрезанного дома/крыши. Сохранить пропорции иллюстрации в компактной полосе.

### Заставка

По новому референсу: тёмно-синий фон с мягким градиентом, название в верхней
трети с узким бирюзовым акцентом, текст **«Подготавливаем расчёт…»**,
большая непрерывная труба с вентилем слева, изгиб вниз, светящийся поток к
контурному дому справа, тёплое четырёхчастное окно, мягкие холмы внизу.
Узнаваемая композиция снимка, без внешней серой рамки фотографии.
Ненавязчивая анимация потока; reduced motion даёт полноценный статичный вид.
При необходимости скорректировать только splash geometry, чтобы композиция
не сжималась в текущие 520×320; ориентир **560×450**, в пределах экрана/DPI.
Основное окно не увеличивать. Readiness/lifecycle/ошибки/loopback не менять,
не добавлять искусственную задержку. Диагностический splash-hold допустим
исключительно для evidence, не нормального запуска.

### Установщик

Настоящий русский Inno Setup wizard получает фирменную боковую welcome/finish
иллюстрацию и малую верхнюю иллюстрацию внутренних страниц, согласованные
с заставкой (труба/дом/тёплое окно/синий/бирюза). По возможностям установленной
версии настроить цвета и типографику штатными средствами, сохранив контраст,
стандартные работающие кнопки/ошибки, масштабирование и RU-only flow.
Не заменять настоящий installer макетом/веб-страницей. Не добавлять сетевые
загрузки/новые зависимости ради оформления. Векторную графику для BMP/PNG
можно экспортировать локально воспроизводимым helper script.

### Допустимые дополнительные улучшения

Единая шкала бирюзовых акцентов, аккуратные состояния hover/focus/selected,
мягкие тени и границы карточек, немного более собранная типографика и тёплая
карточка итоговой суммы. Не делать широкий редизайн формы и не менять смысл,
порядок обязательных полей, математику, названия режимов или размер окна.
Читабельность и близость к референсам важнее украшений.

## Обязательные критерии для frozen checklist

- Side-by-side header/footer/splash с каждым соответствующим референсом:
  проверяются перечисленные выше геометрия, штрихи, объём, цвет, пропорции,
  отсутствие clipping и лишних деталей, а не просто наличие трубы и дома.
- Реальные native screenshots основного окна target800×540/min760×520 и
  browser desktop/mobile390×844; во всех трёх режимах action/total доступны,
  при desktop scrollY=0, без CSS/JS только для скриншота/zoom workaround.
- Настоящая native splash screenshot и readiness/close/error-path evidence;
  reduced motion. Заставка достаточно близка новому референсу визуально.
- Реальный installer: welcome, dir/tasks, installing, finish; все RU,
  согласованная графика, читаемые кнопки; actual installed app с новым видом.
  Изолированный install/uninstall/reinstall с сохранением чужих user files,
  HKCU/ярлыков и обычной установки. Не занимать её AppId/каталог без изоляции.
- ГСН/ГСВ/общая смета, mixed lengths и итоги из утверждённых эталонов,
  САКЗ/ПК/район/НДС сохранены. Backend/API/calculator files не менять.
- `.\.venv\Scripts\python.exe -m unittest discover -s tests` и требуемые
  packaging проверки: exact command/CWD/exit/log/revision, без имитации.
  Старые static assertions обновлять только там, где явно изменился дизайн;
  не ослаблять реальные функциональные/безопасностные проверки.
- Установщик1.2.0 локально, SHA256 и путь; old artifacts/remote releases intact;
  финальный независимый PASS по фактическому diff/evidence.
