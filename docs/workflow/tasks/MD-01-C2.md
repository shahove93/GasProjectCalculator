## Required correction

1. Валидация должна различать отсутствие ключа и явный `null` — проверять
   фактическое присутствие ключей исходной формы (например,
   `model_validator(mode="before")` по сырому dict / `model_fields_set`), не
   только `is not None` после парсинга.
2. Отклонять 422 как минимум:
   - mixed-валидный + `"length": null`;
   - mixed-валидный + `"diameter": null`;
   - legacy-валидный + `"pipe_lengths": null`;
   - `"pipe_lengths": null` вместе/вместо legacy и прочие уже покрытые
     неполные/смешанные формы.
   Одинаково для standalone и combined.
3. Валидные mixed и legacy запросы должны по-прежнему давать прежние суммы и
   форму ответа (D1–D12 не регрессируют).
4. Добавить regression assertions на 422 для standalone и combined; полный
   suite прогнать один раз на исправленном diff.
