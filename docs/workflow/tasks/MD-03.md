Собрать packaged app и новый локальный x64 installer версии 1.1.0 из принятого
MD-02, установить в изолированный test instance, запустить реальную
установленную программу и доказать новые mixed-поля/эталоны, отсутствие
регрессий ГСН/опций и прежний lifecycle/installer flow. Артефакт передать
локально с точным path/size/SHA256.

## Build/version requirements

1. `AppVersion`/`AppVerName`/`VersionInfoVersion` = `1.1.0`/`1.1.0.0`;
   `OutputBaseFilename` даёт `GasProjectCalculator-Setup-1.1.0.exe`. `AppId`
   сохранить, чтобы upgrade/reinstall прежней per-user установки работал.
2. Прежние артефакты 1.0.0 и legacy не перезаписывать; записать их size/SHA256
   до и после сборки и доказать неизменность.
3. Сборка — локальная, без сети/подписи; использовать существующий проверенный
   toolchain. Ошибки сборки не маскировать.

## Verification requirements

1. Установить новый installer в отдельный test instance (`/DIR=...`,
   per-user, без постоянного изменения пользовательской установки), с
   backup/restore HKCU uninstall key и ярлыков Start Menu/Desktop.
2. Запустить установленную программу без Python/CLI; снять реальные
   native screenshots: окно, splash/readiness, три режима, mixed-эталоны,
   compact 800×540 / min 760×520, `scrollY=0`, action+итог видимы.
3. Проверить mixed: 4/0/4 → 75600; 2/4/3 → 79275; 0/5/2 → 71400; 3/1/1 →
   63000; 8/0/0 → 70875 (частник/город/без опций), плюс общий пример
   151000/7550/158550. Проверить legacy-форму и 422 смешения.
4. Проверить ГСН-регрессию (прежние значения), САКЗ/ПК/район/НДС 5%,
   переключение режимов, ПК при 0 САКЗ.
5. Lifecycle: native splash, loopback-only, занятый порт (свой test port),
   закрытие окна завершает backend; не оставлять дочерних процессов.
6. Установщик: русский wizard, Start Menu/optional Desktop, reinstall,
   uninstall с сохранением пользовательских файлов; прежний release не
   затрагивать.
