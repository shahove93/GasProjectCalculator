## Goal

Привести native window к бренду `СС.Расчет`, размеру 1050×740 (минимум
860×620) и добавить короткую локальную русскую заставку запуска с анимацией
потока газа по трубе к дому. Заставка видна только пока backend запускается,
исчезает при readiness, не создаёт искусственной задержки, уважает reduced
motion и не использует сеть. Ошибки запуска остаются понятными и русскими.

## Allowlist

- `app/desktop_launcher.py` — заголовок/размер окна, lifecycle заставки,
  диагностические хуки.
- Новый `frontend/splash.html` и локальные ассеты заставки (при необходимости).

- `docs/workflow/evidence/RD-02-*`, `docs/workflow/evidence/logs/RD-02-*`,
  `docs/screenshots/rd-02-*`.
- Не менять `app/main.py`, `app/calculator.py`, `app/gsv_calculator.py`,
  `frontend/index.html` (функциональная часть RD-01), installer, user data.

## Required behavior

1. `APP_TITLE` ровно `СС.Расчет` (без подписи в title). Подпись
   `Калькулятор ГСН и ГСВ` остаётся в шапке приложения.
2. Окно: ширина 1050, высота 740; минимум (860, 620).
3. Заставка:
   - локальная страница на русском, без сети (file/data URI);
   - ненавязчивая анимация газа по трубе к дому; при reduced motion —
     статичное/отключённое состояние;
   - показывается только во время старта backend;
   - закрывается/исчезает при readiness backend; главное окно приложения
     появляется после readiness (сохранить прежнее поведение);
   - нет искусственной минимальной длительности/задержки;
   - при ошибке старта заставка закрывается, показывается понятная русская
     ошибка, backend не остаётся.
4. Сохранить lifecycle: только `127.0.0.1`, пропуск занятых портов, закрытие
   окна останавливает backend, developer uvicorn не затронут.
5. Не писать пользовательские данные в каталог установки.
6. Для доказательства splash lifecycle допустим диагностический хук только
   для теста/скриншота; он не должен влиять на обычный запуск. Обычный запуск
   обязан стартовать без искусственной задержки.
