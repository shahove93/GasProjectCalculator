## Goal

Собрать заново упакованное приложение с новым интерфейсом/эмблемой/окном/
заставкой и собрать чистый локальный x64 installer с полностью русским
мастером, ярлыком `СС.Расчет` (Start Menu + опциональный Desktop), понятными
ошибками и русским удалением. Артефакт остаётся локальным.

## Required installer behavior

1. Inno Setup wizard только на русском: страницы, кнопки, задачи, ошибки,
   финиш и uninstaller. `ShowLanguageDialog=no`.
2. `AppName`/ярлыки ровно `СС.Расчет`; Start Menu всегда, Desktop — опция
   (по умолчанию выключена). Рабочая папка и target — установленный exe.
3. Publisher — `ООО «Северное сияние»` (утверждённый бренд); не выдумывать
   реквизиты.
4. Per-user установка без UAC, `PrivilegesRequired=lowest`,
   `ArchitecturesAllowed=x64compatible`, без записи пользовательских данных в
   каталог установки.
5. Собрать packaged app (`packaging\build.ps1`) и installer
   (`installer\build-installer.ps1`); артефакт в `installer/Output/`, exact path,
   size, SHA256.
6. Clean install, reinstall и uninstall сохраняют пользовательские файлы вне
   каталога установки. Uninstall удаляет файлы программы и ярлыки.
7. Установленное приложение: без Python/консоли, окно `СС.Расчет`, заставка,
   все три режима 131250/105525/145950, только `127.0.0.1`, закрытие окна
   освобождает порт.
8. Никакой подписи, автообновления, телеметрии, cloud, публикации.
9. Developer uvicorn и полный suite остаются рабочими.
