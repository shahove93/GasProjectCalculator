## Goal

Перестроить presentation так, чтобы реальное native-окно стало компактным
(~800×540, min ~760×520), плотным и визуально близким левому референсу:
шапка с эмблемой и трубой/вентилем, переключатель режимов наверху, заказчик,
параметры парами, результат справа с заметным итогом, нижняя трубная
иллюстрация с домом. Вычисления, API, payload, пользовательские данные не
менять.

## Required design

1. Компактная тёмная шапка: круглая эмблема, `СС.Расчет`, подпись
   «Калькулятор ГСН и ГСВ», трубная графика с вентилем; не копировать
   вымышленные цифры/поля из генерации.
2. Переключатель трёх режимов наверху, заказчик рядом/строкой ниже.
3. Параметры и результат — две карточки рядом уже при target/min; поля
   группировать парами в строке, плотные строки; все поля всех режимов
   доступны. В combined все обязательные параметры доступны без потери.
4. Результат справа: заметный итог; детализация может прокручиваться/
   раскрываться в собственной области, но итог и действие остаются видимы.
5. Нижняя декоративная труба с домом/пламенем/вентилем по мотиву референса.
6. Плотность: межстрочные интервалы и отступы примерно вдвое меньше прежних;
   ориентир текста 13–14 px, полей 28–32 px, padding карточек 10–12 px.
   Никаких CSS `zoom`/`scale`/transform для имитации компактности. Текст
   читается без увеличения.
7. Убрать не working-around: page не должен скрывать переполнение
   `overflow-x:hidden`, если оно маскирует горизонтальный overflow.
8. Mobile 390 px: без horizontal overflow, поля/кнопка доступны.
9. Reduced motion и отсутствие внешних ресурсов сохранить.
