## Rebuild and verification

1. До сборки сохранить текущий installer в
   `installer/Output/legacy/GasProjectCalculator-Setup-1.0.0-previous-stage.exe`
   (или эквивалент) с hash; не перезаписывать прежний legacy.
2. Собрать `packaging\build.ps1`, затем `installer\build-installer.ps1`.
   Записать точный artifact path, size, SHA256, exit codes/logs.
3. Чистая установка нового installer per-user в отдельный test instance;
   запустить установленную программу без Python/CLI.
4. Реальные native screenshots установленного окна в сопоставимом масштабе с
   before (`rd-03-installed-main.png`/`rd-05-before`): target/min, все три
   режима до/после расчёта, `scrollY=0`, action+итог видимы, без workaround/
   hidden clipping. Записать outer/client size, DPI.
5. Проверить установленную программу: три значения 131250/105525/145950,
   САКЗ/ПК, switch/422, mobile 390 (browser viewport) без horizontal overflow.
6. Lifecycle: splash/ready, loopback-only, port conflict, закрытие окна
   завершает backend. Неизменные части (RD-02/RD-03) можно переиспользовать
   по evidence-reuse с явной ссылкой; заново проверять только затронутое
   пересборкой и реальный установленный артефакт.
7. Reinstall/uninstall: переиспользовать RD-03 evidence, если installer flow
   не менялся; иначе — минимально доказать сохранение user files.
8. Не оставлять запущенных test backend/окон; освободить ресурсы.
