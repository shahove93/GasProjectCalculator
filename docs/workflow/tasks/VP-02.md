## Build/version requirements

1. `AppVersion`/`AppVerName`/`VersionInfoVersion` = `1.2.0`/`1.2.0.0`;
   `OutputBaseFilename` даёт `GasProjectCalculator-Setup-1.2.0.exe`. `AppId`
   сохранить, чтобы upgrade/reinstall прежней per-user установки работал.
2. Настоящий русский Inno Setup wizard: welcome/finish получают фирменную
   боковую иллюстрацию, внутренние страницы — малую верхнюю; мотив согласован
   с заставкой (труба/дом/тёплое окно/синий/бирюза). Использовать штатные
   средства установленной версии (WizardImageFile/WizardSmallImageFile,
   цвета/типографика), сохранив контраст, стандартные работающие кнопки/
   ошибки, масштабирование и RU-only flow.
3. Не заменять настоящий installer макетом/веб-страницей. Не добавлять
   сетевые загрузки/новые зависимости ради оформления. Векторную графику для
   BMP/PNG можно экспортировать локально воспроизводимым helper script.
4. Сборка локальная, без сети/подписи, существующим toolchain. Ошибки сборки
   не маскировать.
5. **До build** записать size+SHA256 всех прежних installers; после build
   доказать их неизменность.

## Verification requirements (реальные проверки)

1. Собрать packaged app и новый installer 1.2.0; записать path/size/SHA256,
   FileVersion/ProductVersion, unchanged old hashes.
2. Изолированная установка нового installer в отдельный test instance
   (`/DIR=...`, per-user) с backup/restore HKCU uninstall key и ярлыков
   Start Menu/Desktop; проверить, что обычная пользовательская установка/файлы
   не изменены.
3. Реальный RU wizard: welcome, dir, tasks, installing, finish — screenshots;
   вся согласованная графика видна, кнопки читаемы.
4. Запустить установленную программу без Python/CLI; реальные native
   screenshots: новое основное окно, новая заставка, три режима, mixed-
   эталоны, compact 800×540 / min 760×520, `scrollY=0`, action+итог видны.
5. Проверить значения: mixed 4/0/4→75600; 2/4/3→79275; 0/5/2→71400;
   3/1/1→63000; 8/0/0→70875; combined 151000/7550/158550; legacy/422;
   ГСН-регрессия; САКЗ/ПК/район/НДС 5%; переключение режимов.
6. Lifecycle: loopback-only, занятый test-порт, закрытие окна завершает
   backend, без дочерних процессов.
7. Install/upgrade/reinstall/uninstall: сохранение user files, HKCU/ярлыки,
   прежний release не затронут.
8. Полный integrated suite в этом TASK не повторять без причины; targeted
   packaging/installer tests и реальные проверки — да. Финальный полный suite
   исполнит координатор один раз по конечной ревизии.
