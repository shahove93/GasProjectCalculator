## Precondition

WI-01 must be accepted and committed. Baseline is the WI-01 commit; the packaged
onedir application must already build and run.

## Goal

Produce a Windows x64 installer with Inno Setup that installs the packaged
application, creates a Start Menu shortcut and an optional Desktop shortcut, lets
a user launch it without Python or a terminal, and uninstalls without deleting
user files. Build the installer as a local artifact and report its exact path and
SHA256.

## Toolchain

- Inno Setup 6 portable compiler (verified):
  `C:\Users\user\AppData\Local\Temp\edr-windows-build\inno\ISCC.exe`.
  Do not install system-wide; do not change global settings/accounts.
  Prefer resolving via `$env:ISCC_PATH` or a build-script fallback to this path;
  do not commit the compiler binary.
- PyInstaller build from WI-01 (onedir, windowed). Installer must not require
  Python or a console on the target machine.

## Allowed changes (allowlist)

- New `installer/` directory: `.iss` script, optional assets, build/verify scripts.
- Small build-script changes in `packaging/` needed to build the installer.
- Evidence files under `docs/workflow/evidence/` named `WI-02-*`.
- `.gitignore` additions for installer/build output.
- Do NOT edit application behavior or planning/workflow docs. Do not commit.

## Required installer behavior

1. Per-user installation that works without administrator rights and without
   UAC where possible (e.g. `PrivilegesRequired=lowest`, default dir under
   LocalAppData). Do not write user data into the installation directory.
2. Start Menu shortcut always created; Desktop shortcut optional (installer task,
   unchecked by default or clearly optional).
3. Installed app launches the packaged native-window application with no Python
   and no terminal; first launch waits for backend readiness; backend listens on
   localhost only and handles port conflicts.
4. Closing the window exits the application and backend (no leftover process or
   listening port).
5. Uninstall removes installed program files and shortcuts but never deletes
   user-created files elsewhere (Documents/Desktop/user data).
6. Understandable launch failure (message, not only a silent exit).
7. Existing developer uvicorn path and all three modes remain intact.
8. No code signing, auto-update, telemetry, cloud, publication or release.
